# KWGT 小组件配置指南

## 1. 安装 KWGT

在 Google Play 搜索并安装 **KWGT Kustom Widget Maker**（免费版即可）。

可选：安装 **KWGT Pro Key**（付费，解锁更多功能，如导入导出预设）。

## 2. 在桌面添加小组件

1. 长按桌面空白处 → 选择「小组件 / Widget」
2. 找到 KWGT，选择你想要的尺寸（推荐 **4×2** 或 **4×1**）
3. 将小组件拖到桌面
4. 点击小组件进入编辑器

## 3. 配置小组件显示随机句子

### 步骤 1：创建文本元素

1. 点击右上角 **+** → 选择 **Text**
2. 在文本内容中，清空默认文字，输入以下公式：

```
$wg("http://你的服务器IP:8000/quotes/random", json, ".text")$
```

> 把 `你的服务器IP` 替换为你的实际服务器地址。
> 
> 本地测试可以用 `adb reverse tcp:8000 tcp:8000` 映射端口，然后用 `http://127.0.0.1:8000/quotes/random`。

### 步骤 2：调整样式

在 **Text** 项的属性面板中：
- **Size**：调整字体大小（推荐 16-20）
- **Color**：设置文字颜色
- **Font**：选择字体（中文字体推荐默认或 Noto Serif）
- **Width**：设为小组件宽度
- **Padding**：上下左右各 12-16
- **Max Lines**：设为 3-5，超出自动省略

### 步骤 3：设置点击刷新

1. 选中整个根组件（或 Text 项）
2. 点击 **Touch / 触摸** 标签
3. 添加一个触摸动作：
   - Action：**Kustom Action** → **Force Update / 强制刷新**
4. 这样点击小组件就会重新请求 API，显示新句子。

### 步骤 4：设置自动刷新

1. 在根组件设置中
2. 找到 **Update Mode / 更新模式**
3. 选择 **Fast**（每 30 分钟刷新）或自行调整

## 4. 完整公式参考

如果 API 返回的数据结构是 `{"id": 1, "text": "xxx", "source": "xxx", "created_at": "xxx"}`：

| 用途 | 公式 |
|------|------|
| 显示句子文本 | `$wg("http://IP:8000/quotes/random", json, ".text")$` |
| 显示来源+编号 | `$wg("http://IP:8000/quotes/random", json, ".source")$` |
| 网络不可用时显示 | `$if(wg("http://IP:8000/quotes/random", json, ".text"), wg("http://IP:8000/quotes/random", json, ".text"), "暂无句子")$` |

## 6. 常见问题

### Q: KWGT 提示网络错误？
- 检查手机和服务器的网络连通性
- 确认服务器端口已开放（8000）
- 尝试用手机浏览器访问 `http://IP:8000/quotes/random` 看能否打开

### Q: 中文显示乱码？
- KWGT 设置中调整字体，选择支持中文的字体

### Q: 句子太长显示不全？
- 增加 Max Lines 数量
- 或减小字体大小
- 或设置 `$tc(ell, wg(...), 80)$` 截断到 80 个字符
